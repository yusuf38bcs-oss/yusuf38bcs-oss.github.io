    options:
    - a: Genus
    - b: Order
    - c: Class
    - d: Phylum
    correct_key: b
    explanation: 'The standard taxonomic hierarchy is: Kingdom → Phylum → Class →
      Order → Family → Genus → Species. Therefore, Order ranks immediately above Family.'

    question_text: Which protozoan group is exclusively parasitic and lacks locomotor

    options:
    - a: Rhizopoda
    - b: Ciliata
    - c: Sporozoa
    - d: Flagellata
    correct_key: c
    explanation: Sporozoans (Apicomplexa) are entirely parasitic and adult forms typically
      lack structures for locomotion, relying on host transmission.
