# Daily 20-Minute Practice

Rotate through **Listening → Reading → Writing → Speaking**. Each session includes one task, a model answer or feedback checklist, key vocabulary, a follow-up drill, and one reflection note.

## Session flow

1. Start the 20-minute timer.
2. Complete the task without checking the model.
3. Review the Band 8 checklist.
4. Record one recurring error.
5. Repeat the weak part once.

> Interactive timer and progress persistence will be added in the next implementation phase.
