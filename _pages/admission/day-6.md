  <section class="lbfl-assessment-panel">
    <h2>Today's loop</h2>
    <p><strong>Learn → recall without notes → solve → submit or check → explain → repair → retest.</strong> Use a notebook for working. The page is a guide, not a substitute for a full syllabus or an official question paper.</p>
  </section>

  <h2>Four subject capsules</h2>
  <div class="lbfl-info-grid">
    <section class="lbfl-info-card"><h3>Physics</h3><ul><li>Write complete solutions: principle, equation, substitution, unit, direction and one sentence of interpretation.</li><li>For a wrong answer, decide whether the error was concept, model, algebra, unit, sign or reading.</li><li>A corrected solution is not complete until the same idea can be solved without copying.</li></ul></section>
    <section class="lbfl-info-card"><h3>Chemistry</h3><ul><li>Use a fixed calculation order: equation, known data, moles, ratio, requested quantity, unit check.</li><li>For atomic questions, separate atomic number, mass number, isotope and ion charge.</li><li>Explain the reason for a trend rather than memorising an isolated arrow.</li></ul></section>
    <section class="lbfl-info-card"><h3>Higher Mathematics</h3><ul><li>Write each derivative step legibly and preserve brackets.</li><li>Check a stationary point by substituting back into the original function when appropriate.</li><li>Use an error log to identify repeated algebra patterns.</li></ul></section>
    <section class="lbfl-info-card"><h3>Biology</h3><ul><li>Retrieve organelle function and cell-division sequence from memory before opening the source.</li><li>Link genetics terms to information flow: DNA, gene, allele, expression and phenotype.</li><li>A retrieval answer should include a precise term and a reason, not a vague keyword.</li></ul></section>
  </div>

  <h2>Recall without notes</h2>
  <ol><li>Rewrite one earlier wrong Physics solution with the error type named.</li><li>Balance and solve one stoichiometry problem without looking at an example.</li><li>Differentiate and classify a stationary point in one complete written solution.</li><li>Explain how a gene can influence phenotype without implying a single-cause rule.</li></ol>

  <h2>Practice and application</h2>
  <ol><li>Complete one written problem per Physics theme and mark units.</li><li>Complete one stoichiometry and one atomic-structure written response.</li><li>Complete two calculus written responses and self-check each line.</li><li>Run a cell-and-genetics retrieval grid, then return to the source only for gaps.</li></ol>
