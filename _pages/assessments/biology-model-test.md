# HSC Biology Model Test

<section class="lbfl-assessment-hero">
  <p class="lbfl-assessment-kicker">CQ Studio · Bloom Rubric · Board Pattern</p>

## Recommended Model-Test Structure

<div class="lbfl-assessment-grid">
  <section class="lbfl-cq-card"><h3>MCQ</h3><p class="lbfl-cq-text">Terms, functions, diagrams, comparisons, and mechanism logic. Solve first, then read explanation.</p></section>
  <section class="lbfl-cq-card"><h3>Short Answer</h3><p class="lbfl-cq-text">Definitions, reasons, examples, and biological significance. Write concise answers.</p></section>
  <section class="lbfl-cq-card"><h3>Creative Question</h3><p class="lbfl-cq-text">Stem analysis, data or diagram interpretation, and application. Identify concept before writing.</p></section>
  <section class="lbfl-cq-card"><h3>Diagram</h3><p class="lbfl-cq-text">Labelled structure, flowchart, and process map. Draw with correct sequence.</p></section>
  <section class="lbfl-cq-card"><h3>Reflection</h3><p class="lbfl-cq-text">Mistake analysis and next revision target. Write a weakness list after scoring.</p></section>
</div>

## How to Use a Model Test Properly

<section class="lbfl-assessment-panel">
  <ol>
    <li><strong>Read the topic list:</strong> identify which chapters are included.</li>
    <li><strong>Attempt without help:</strong> use a timer and avoid notes.</li>
    <li><strong>Review wrong answers deeply:</strong> explain why the correct answer is valid.</li>
    <li><strong>Return to the lesson:</strong> revise concept, diagram, or wording weakness.</li>
    <li><strong>Repeat after correction:</strong> test similar concepts again.</li>
  </ol>
</section>

## Model-Test Quality Rule

<section class="lbfl-assessment-panel">
  <p class="lbfl-assessment-lead">A useful Biology model test must train concept recognition, diagram interpretation, term precision, and reasoning. The best test is not the one with the most questions; the best test is the one that clearly shows what the learner understands, which source lesson must be revised, and what should be tested again next.</p>
