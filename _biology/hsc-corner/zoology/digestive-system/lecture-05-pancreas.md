# Digestive System Lecture 05

এই lecture-এ অগ্ন্যাশয়, duodenum এবং digestive juice-এর ভূমিকা আলোচনা করা হয়েছে।

## Key Points

- অগ্ন্যাশয় digestion-এ সহায়ক।
- এর juice duodenum-এ কাজ করে।
- Carbohydrate, protein ও lipid breakdown-এ এটি প্রয়োজন।
