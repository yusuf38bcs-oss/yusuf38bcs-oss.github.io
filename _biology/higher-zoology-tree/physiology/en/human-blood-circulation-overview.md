## High-Yield Comparison Table

| Concept | Must Remember | Common Trap |
|---|---|---|
| Plasma | Liquid transport medium | Thinking it is only water |
| RBC | Oxygen transport through hemoglobin | Calling it an immune cell |
| WBC | Defence and immunity | Calling it oxygen carrier |
| Platelet | Hemostasis and clotting | Calling it a full WBC type |
| Lymph | Tissue fluid return and immunity | Thinking it contains many RBC |
| SAN | Natural pacemaker | Thinking nerve starts every beat |
| AVN | Delays impulse | Thinking delay is useless |
| Pulmonary circulation | RV → lungs → LA | Confusing with systemic route |
| Systemic circulation | LV → body → RA | Forgetting aorta and vena cava |
| Angina | Temporary oxygen shortage | Same as heart attack |
| Heart attack | Myocardial damage from blocked flow | Simple chest discomfort only |
| CABG | Creates bypass route | Opens the same blocked artery |
| Stent | Keeps artery open | A medicine tablet |
