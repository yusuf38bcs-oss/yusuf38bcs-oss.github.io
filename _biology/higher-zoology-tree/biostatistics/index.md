# Biostatistics Course — Biological Data to Inference

Biostatistics converts biological observations into measurable evidence. This governed course moves in one deterministic sequence from data foundations and graphical description to descriptive statistics, hypothesis testing, inferential tests, and relationship analysis.

## How to use the course

1. Define the biological question before choosing a statistic.
2. Identify the variable, measurement scale, sample and comparison structure.
3. Describe the data before applying an inferential test.
4. Match the statistical method to the data and assumptions.
5. Show the calculation or analytical logic.
6. Interpret the result in biological language.
7. Keep **statistical significance** separate from **biological importance**.

## Canonical ownership and legacy aliases

The hyphenated central-tendency and dispersion lessons and the dedicated Z-test lesson are the canonical learning nodes. Historical underscore/combined routes remain compatibility redirects and are not counted as separate modules.

## Assessment boundary

Use worked problems, data interpretation, method-selection questions and MCQs. A p-value or statistical test result is evidence within a biological argument; it is not a substitute for effect size, study design, biological mechanism or scientific judgment.
