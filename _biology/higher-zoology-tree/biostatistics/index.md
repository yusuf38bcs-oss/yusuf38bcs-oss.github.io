Biostatistics Terminal converts biological observations into measurable evidence. This gateway connects data collection, frequency distribution, central tendency, dispersion, graphical presentation, and biological interpretation.

## Core Learning Route

- **Data foundation:** variable, observation, population, sample, and frequency.
- **Descriptive statistics:** mean, median, mode, range, variance, standard deviation, and coefficient of variation.
- **Graphical presentation:** frequency table, histogram, polygon, and biological data visualization.
- **Biological interpretation:** use numbers to explain variation, pattern, and evidence in living systems.

1. Identify the biological question.
2. Define the variable and data type.
3. Summarize data with a suitable table or graph.
4. Choose the correct descriptive statistic.
5. Interpret the result in biological language.
