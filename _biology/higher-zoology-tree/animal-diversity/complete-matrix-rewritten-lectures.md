## Student Decision Tree

```text
Animal sample
  ↓
True tissue absent? → Porifera
  ↓
Diploblastic + cnidocyte? → Cnidaria
  ↓
Triploblastic? → check coelom
  ↓
Acoelomate → Platyhelminthes
Pseudocoelomate → Nematoda
True coelomate → check segmentation, appendage, mantle, water vascular system or notochord
```

## Final Revision Grid

  <section><strong>Cnidaria</strong><span>Representative: Obelia</span><span>Diagnostic: Cnidocyte + coelenteron</span><span>Must know: Polyp-medusa; planula; metagenesis.</span></section>
  <section><strong>Platyhelminthes</strong><span>Representative: Taenia/Fasciola</span><span>Diagnostic: Flat body + flame cell</span><span>Must know: Host switching; larval stages.</span></section>
  <section><strong>Nematoda</strong><span>Representative: Ascaris</span><span>Diagnostic: Pseudocoel + cuticle</span><span>Must know: Direct life cycle with migration.</span></section>
  <section><strong>Mollusca</strong><span>Representative: Pila/Sepia</span><span>Diagnostic: Mantle + foot</span><span>Must know: Shell/torsion; cephalopod adaptations.</span></section>
  <section><strong>Annelida</strong><span>Representative: Neanthes/Hirudo</span><span>Diagnostic: Metamerism</span><span>Must know: Swarming/trochophore; cocoon.</span></section>
  <section><strong>Arthropoda</strong><span>Representative: Insects</span><span>Diagnostic: Jointed appendages</span><span>Must know: Mouthparts; metamorphosis; tracheae.</span></section>
