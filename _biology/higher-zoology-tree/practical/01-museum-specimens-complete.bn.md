# Study of Museum Specimens — Complete NU Coverage

## Classification, Figure Cues & Identifying Characters

**মূল Lecture:** বাংলা  
**Technical Terms:** English  
**Coverage:** **48/48 unique syllabus labels**

NU list-এ `Echinus` দুইবার printed; তাই 49 printed entries থেকে **48 unique labels** পাওয়া যায়। এই page সব 48 unique label cover করে।

## Museum Practical Answer Pattern

**Specimen → Classification → 3–5 visible identifying characters → one diagnostic character → identification conclusion**

> Habitat বা disease information supporting evidence হতে পারে; preserved specimen spotting-এ প্রথম evidence হবে **visible morphology**।

## Figure Policy

প্রতিটি specimen-এর জন্য local asset path:
`/assets/biology/higher-zoology-tree/practical/museum-specimens/<slug>.svg`

Figure-এ minimum:
1. silhouette / orientation;
2. 2–5 diagnostic labels;
3. scale বা “not to scale” note;
4. source/licence metadata যদি external reference থেকে adapted হয়।

## 1. Sycon — *Sycon ciliatum*

**Common name:** Calcareous sponge / purse sponge  
**Figure:** `museum-specimens/sycon.svg`

### Classification

| Rank | Taxon |
|---|---|
| Kingdom | Animalia |
| Phylum | Porifera |
| Class | Calcarea |
| Subclass | Calcaronea |
| Order | Leucosolenida |
| Family | Sycettidae |
| Genus | *Sycon* |
| Representative | *Sycon ciliatum* |

### শনাক্তকারী বৈশিষ্ট্য

- দেহ ছোট, vase-shaped বা cylindrical এবং substratum-এর সঙ্গে attached।
- শীর্ষে terminal **osculum** থাকে।
- Osculum-এর চারপাশে long calcareous **spicules**-এর fringe থাকে।
- Body wall-এ অসংখ্য **ostia** থাকে।
- Canal system **syconoid type**; skeleton calcareous spicules-নির্মিত।

**Diagnostic character:** Porous body + terminal osculum + calcareous spicules.

### Practical identification

> অসংখ্য ostia, terminal osculum এবং calcareous spicules-এর কারণে specimen-টি *Sycon*।

**Taxonomy / syllabus note:** Family-level usage sourceভেদে পরিবর্তিত হতে পারে; exam-এ departmental classification preserve করবে।

## 2. Physalia — *Physalia physalis*

**Common name:** Portuguese man-of-war  
**Figure:** `museum-specimens/physalia.svg`

### Classification

| Rank | Taxon |
|---|---|
| Kingdom | Animalia |
| Phylum | Cnidaria |
| Class | Hydrozoa |
| Clade | Hydroidolina |
| Order | Siphonophorae |
| Suborder | Cystonectae |
| Family | Physaliidae |
| Genus | *Physalia* |
| Species | *P. physalis* |

### শনাক্তকারী বৈশিষ্ট্য

- এটি একক medusa নয়; একটি **polymorphic colonial hydrozoan**।
- উপরের gas-filled **pneumatophore** নীল-বেগুনি float তৈরি করে।
- Float-এ crest/sail-like ridge থাকে।
- নিচে food-capture ও defence-এর জন্য বহু zooid ও অত্যন্ত দীর্ঘ **tentacles** থাকে।
- Tentacles-এ শক্তিশালী nematocysts থাকে।

**Diagnostic character:** Large gas-filled pneumatophore with long trailing tentacles in a siphonophore colony.

### Practical identification

> Gas-filled pneumatophore এবং long tentacular zooids থাকার কারণে specimen-টি *Physalia*।

## 18. Hirudo — *Hirudo medicinalis*

**Common name:** Medicinal leech  
**Figure:** `museum-specimens/hirudo.svg`

### Classification

| Rank | Taxon |
|---|---|
| Kingdom | Animalia |
| Phylum | Annelida |
| Class | Clitellata |
| Subclass | Hirudinea |
| Order | Hirudinida |
| Family | Hirudinidae |
| Genus | *Hirudo* |
| Species | *H. medicinalis* |

### শনাক্তকারী বৈশিষ্ট্য

- Body dorso-ventrally flattened।
