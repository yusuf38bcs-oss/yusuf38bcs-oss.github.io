# Preparation and Study of Whole Mounts

Whole mount-এর উদ্দেশ্য হলো ছোট specimen/organ-কে section না কেটে সম্পূর্ণ অবস্থায় এমনভাবে mount করা যাতে overall organization দেখা যায়।

## Core Workflow

```text
Select small specimen
      ↓
Clean / relax if required
      ↓
Fix according to departmental SOP
      ↓
Wash
      ↓
Stain if necessary
      ↓
Differentiate / dehydrate if permanent
      ↓
Clear if required
      ↓
Mount
      ↓
Label + observe + draw
```

## Suggested Whole-mount Set

| Preparation | Main labels |
|---|---|
| Hydra whole mount | tentacles, hypostome, basal disc, bud |
| Planarian whole mount | auricles, eyespots, pharynx region |
| Rotifer whole mount | corona, mastax, trunk, foot |
| *Daphnia* whole mount | carapace, antennae, eye, brood chamber |
| *Cyclops* whole mount | antennules, median eye, thorax, abdomen, egg sacs |
| Mosquito larva | head, thorax, abdomen, siphon (species dependent) |
| Mosquito pupa | cephalothorax, respiratory trumpets, abdomen, paddles |
| Cockroach mouthparts | individual parts in correct orientation |
| Prawn appendage | basal protopod + rami/segments as applicable |
| Nematode small specimen | anterior/posterior and sex-specific structures |

## Temporary Whole Mount

ছোট living/fresh material-এর জন্য water, saline বা suitable mounting medium ব্যবহার করা যায়। Coverslip বসানোর সময় specimen crush না হওয়ার জন্য spacer প্রয়োজনে ব্যবহার করবে।

## Permanent Whole Mount

Permanent preparation-এর exact fixative, stain, dehydration, clearing agent ও mounting resin **departmental SOP** অনুযায়ী নির্বাচন করতে হবে। General logic:

1. fixation;
2. adequate washing;
3. optional staining;
4. graded dehydration;
5. clearing;
6. resin mounting.

### Safety note
Ethanol, formalin/formaldehyde, xylene/clearing agents এবং permanent mountants-এর hazard profile আলাদা। Local laboratory SOP, ventilation/fume hood, PPE এবং approved waste stream ছাড়া protocol পরিবর্তন করবে না।

## Quality-control Checklist

- specimen folded নয়;
- key structures overlapping নয়;
- bubbles minimal;
- stain over-dark নয়;
- mountant covers specimen;
- label-এ specimen, date, stain/mountant, preparer;
- slide edge clean;
- diagnostic structure microscope-এ visible।

## Drawing Rule

Whole mount drawing **photographic shading** নয়; scientific line drawing হবে:
- proportional outline;
- diagnostic structure;
- straight label lines;
- no crossed label lines;
- title + magnification/scale.
