# Research Methodology Terminal

This terminal is the gateway for learners who want to understand how academic biology questions are organized, studied, interpreted, and written. It connects observation, question design, variables, data collection, data analysis, and report writing into one learning route.

## Learning path

1. Choose a clear biology question.
2. Define the aim, objective, variable, and expected relation.
3. Select a suitable method and data source.
4. Organize findings in tables, figures, and written explanation.
5. Interpret the result with logic and limitation.
6. Write the final academic report with references.
