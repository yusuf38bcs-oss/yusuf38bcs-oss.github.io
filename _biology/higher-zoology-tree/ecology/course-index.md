# Ecology Course Index

The canonical **29-lecture Ecology course** moves from ecological foundations through population, community and ecosystem ecology to biodiversity, conservation and applied Bangladesh field inquiry.

{% include education/framework-links.html %}

## Course Architecture

```text
Foundation → Population → Community → Ecosystem → Biodiversity → Conservation → Bangladesh application
```
